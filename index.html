1. Overview / 概述

English: CPURAM-Monitor is a lightweight local Windows hardware monitoring application. The software only reads local hardware operating data including CPU usage, RAM usage, hardware temperature and device running status. This application does not collect, store, upload or share any user personal information, private data or device sensitive information. All data generated during operation is completely stored locally on the user’s computer and will not be synchronized to any cloud server or third-party platform.

中文：CPURAM-Monitor 是一款轻量的 Windows 本地硬件监控工具。软件仅读取本机 CPU 占用、内存占用、硬件温度、设备运行状态等硬件运行数据。本应用不会收集、存储、上传、分享任何用户个人信息、隐私数据及设备敏感信息。软件运行产生的所有数据均仅保存在用户本地电脑，不会同步至任何云端服务器或第三方平台。
